## 프로젝트 개요

- Java, Spring Boot 기반 실시간 멀티플레이 게임 서버
- WebSocket을 이용한 카드 사용 및 이벤트 처리
- 카드, 게임판, 사용자 도메인 설계 및 서비스 로직 구현

## 기술 스택

- Java 17 / Spring Boot 3 / JPA / MySQL
- WebSocket (Socket.IO)
- Gradle, Git
